KONFIGURASI OPERATOR
1. Konfigurasi Casir: owners, misalnya
   {active:true,phone:"62...",deviceId:"...@s.whatsapp.net",
    gowaDeviceId:"session-id",ownerId:"owner-terverifikasi",outletIds:["outlet-sah"]}
   Nomor, device, outlet wajib diverifikasi di luar chat. Satu mapping saja per pasangan.
2. Pasang role/credential read-only di 11 tool laporan + Cek Database dan Batas Query.
   Timeout <=10s dan connection limit <=4 diperiksa sebelum AI.
3. Pasang control-schema.sql di casir_automation melalui admin; credential kontrol
   di node casir_control kedua workflow. Role timeout <=3s, lock <=1s, limit <=6.
4. Webhook /webhook/casir-owner-report menggunakan payload modern GoWA:
   {event,device_id,payload:{id,from,chat_id,body,is_from_me,timestamp}}.
   Grup, self, receipt, media nonteks, pertanyaan >1500 karakter, dan event >5 menit
   ditolak. HMAC SHA256 raw body, X-Hub-Signature-256, secret acak >=32 karakter.
   CASIR_GOWA_WEBHOOK_SECRET dan require('crypto') harus tersedia sesuai kebijakan
   runner/env. Jangan melonggarkan akses env global tanpa penilaian.
5. Ingress harus membatasi spam SEBELUM execution n8n dibuat. Admission internal
   saja tidak cukup melindungi server webhook. Rincian di OPERATIONS.txt.
6. Model opencode/credential pengguna dipertahankan, tetapi kompatibilitas tool-calling
   perlu diuji. Penerima balasan berasal dari owner terverifikasi, bukan output AI.
7. Uji staging dahulu. Flag liveEnabled, ingressControlsReady, controlDatabaseReady,
   databaseReady, aiReady, sendReplies masih false sampai semua prasyarat lolos.
   Manual Trigger hanya memeriksa draft, bukan konektivitas/integrasi.
